What the student must do

      
Treat every wire as an elastic spring pulling connected cells closer. Compute each movable cell's target barycenter from its neighbors, blend it with the old coordinate using damping α, and report HPWL alongside minimum spacing so cells shrink wirelength without piling onto one point.


      

        
1Hooke's law: Every wire pulls connected cells together like a gentle spring; longer wires pull harder.

        
2Target barycenter: A cell's zero-force target is the average (x, y) of its connected neighbors.

        
3Damped step: Move part-way each round with new = (1 − α)·old + α·target (sweet spot α ≈ 0.5).

        
4Prevent collapse: Keep corner I/O anchors or spreading forces so cells pack tightly instead of collapsing to one dot.

Pitfalls to watch

      

        
!α too small (e.g. α = 0.05): Cells barely budge per round, wasting runtime before wires shrink.

        
!α too big without anchors (e.g. α = 1.0): Cells overshoot and collapse into an illegal pile-up at the center.

        
!Changing net models mid-check: Always evaluate before (52.0) and after (18.7 / 14.0) HPWL with the exact same net model.
